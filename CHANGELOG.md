# Changelog

## 0.1.0

- Introduced the shared API error envelope for TypeScript and Python.
- Added strict error parsing, typed HTTP transport, nested field paths, locale
  catalogs, and safe internal redirects.
- Added immutable presentation copies, cross-bundle error guards, and
  network/timeout/cancellation normalization.
- Added React/TanStack Query notification and field-error adapters.
- Added Next.js helpers with explicit trusted-proxy and host allow-list policy.
- Added FastAPI handlers and request-id middleware.
- Added shared valid/invalid contract fixtures and architecture boundary tests.
- Added CI, secret scanning, and verified npm/PyPI trusted-publishing workflows.
